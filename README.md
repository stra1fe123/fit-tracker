# Fit Tracker

Личное веб-приложение для тренировок и подсчёта БЖУ. Данные хранятся в Google Таблице.

- **Питание**: подсчёт калорий и БЖУ за день. Продукты запоминаются, повторно их можно найти поиском.
- **Тренировки**: свои тренировки с упражнениями, подходами и весами. Во время занятия отмечаешь подходы галочками. Рабочий вес в плане обновляется сам, приложение подсказывает, когда пора добавить вес.
- **Прогресс**: графики веса тела и рабочих весов в упражнениях.
- **Профиль**: дневная норма ккал и БЖУ по формуле Миффлина–Сан Жеора. Пересчитывается автоматически по среднему весу за 7 дней.
- **Напоминание**: в приложении баннер «Пора взвеситься», плюс письмо на почту в 9 утра, если вес ещё не внесён.

## Как устроено

```
docs/          — само приложение (сайт на GitHub Pages)
apps-script/   — серверная часть: код для Google Apps Script, который пишет данные в таблицу
```

Пока таблица не подключена, приложение работает в локальном режиме: данные хранятся только в браузере.
После подключения их можно перенести в таблицу.

## Настройка (один раз)

### 1. Google Таблица и серверная часть

1. Открой [sheets.new](https://sheets.new). Создастся новая таблица, назови её, например, «Fit Tracker».
2. В меню выбери **Расширения → Apps Script**.
3. Удали всё, что есть в редакторе, и вставь содержимое файла [apps-script/Code.gs](apps-script/Code.gs). Нажми 💾 (Сохранить).
4. В списке функций сверху выбери **setup** и нажми **▶ Выполнить**.
   - Google попросит разрешения: «Проверить разрешения», выбери свой аккаунт.
   - Появится «Google не проверил это приложение». Это нормально, скрипт твой. Нажми **Дополнительно → Перейти к проекту (небезопасно) → Разрешить**.
5. Внизу в «Журнале выполнения» появится строка **«Твой ключ доступа: …»**. Скопируй ключ.
6. Справа сверху **Начать развёртывание → Новое развёртывание**:
   - Шестерёнка ⚙ → тип **Веб-приложение**
   - Запуск от имени: **Я**
   - У кого есть доступ: **Все**
   - **Начать развёртывание**, затем скопируй **URL веб-приложения** (заканчивается на `/exec`).

> Доступ «Все» нужен, чтобы приложение могло достучаться до скрипта. Без ключа доступа скрипт ничего не отдаёт и не записывает.

### 2. Публикация сайта на GitHub Pages

1. Открой репозиторий на GitHub → **Settings → Pages**.
2. Source: **Deploy from a branch**, Branch: **main**, папка **/docs** → **Save**.
3. Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/fit-tracker/`.

### 3. Подключение приложения к таблице

1. Открой сайт → вкладка **Профиль** → блок «Google Таблица».
2. Вставь URL веб-приложения и ключ доступа, нажми **Подключить**.
3. Повтори на каждом устройстве (телефон, компьютер).

### 4. Иконка на экране iPhone

Открой сайт в **Safari** → кнопка «Поделиться» ⬆️ → **На экран «Домой»**.
Приложение будет открываться на весь экран, как обычное.

## Если поменял код серверной части

После правок в `Code.gs`: **Начать развёртывание → Управление развёртываниями → ✏️ → Версия: Новая версия → Развернуть**.
Адрес при этом не меняется.

## Локальный запуск (для разработки)

```bash
py -m http.server 8080 --directory docs
```

Затем открыть http://localhost:8080
